# Block 1: Motor Neuron Pool Model
## Dideriksen et al. (2010) - Exact Model Description

---

## Purpose in the Overall Model

The Motor Neuron Pool Model serves as the **central neural control unit** that:
- Receives descending excitatory drive from the central nervous system
- Recruits and de-recruits motor units according to the size principle
- Generates discharge patterns (spike trains) for each active motor unit
- Accounts for physiological variability in motor neuron firing behavior
- Provides the neural command signals that drive muscle fiber activation

This block transforms a continuous excitatory drive signal into discrete spike trains for individual motor units, which then serve as inputs to the muscle model.

---

## State Variables

According to the paper, each motor neuron in the pool has the following state variables:

### 1. **Membrane Potential: V(t)**
- Represents the voltage across the motor neuron membrane
- Unit: mV (millivolts)
- Evolves according to a leaky integrator model

### 2. **Afterhyperpolarization (AHP): AHP(t)**
- Represents the hyperpolarizing current following each spike
- Unit: mV
- Decays exponentially after each discharge

### 3. **Firing State**
- Binary indicator of whether the motor unit is currently recruited
- Determined by threshold crossing

---

## Parameters

### Motor Unit-Specific Parameters (indexed by i for the i-th motor unit)

#### Recruitment and Threshold Parameters:

**1. Recruitment Threshold: RTE(i)**
- Definition: The effective synaptic drive required to recruit the i-th motor unit
- Distribution: Exponentially distributed across the pool
- Equation (from paper):
  ```
  RTE(i) = RTE₁ · exp[(i-1) · ln(RR) / (n-1)]
  ```
  where:
  - RTE₁ = recruitment threshold of the first motor unit
  - RR = range of recruitment thresholds (ratio of last to first)
  - n = total number of motor units in the pool
  - i = motor unit index (1 to n)

**2. Firing Threshold: θ(i)**
- Definition: Membrane potential threshold for spike generation
- Relationship to recruitment threshold (implicit in paper): θ(i) is proportional to RTE(i)

#### Firing Rate Parameters:

**3. Minimum Firing Rate: f_min(i)**
- Definition: Firing rate at recruitment
- Unit: pulses per second (pps) or Hz
- Distribution: As stated in paper (Section 2.1.2):
  ```
  f_min(i) = f_min,1 - (f_min,1 - f_min,n) · (i-1)/(n-1)
  ```
  where:
  - f_min,1 = minimum firing rate of first motor unit
  - f_min,n = minimum firing rate of last motor unit

**4. Peak Firing Rate: f_peak(i)**
- Definition: Maximum sustainable firing rate
- Unit: pps or Hz
- Distribution: As stated in paper:
  ```
  f_peak(i) = f_peak,1 + (f_peak,n - f_peak,1) · (i-1)/(n-1)
  ```
  where:
  - f_peak,1 = peak firing rate of first motor unit
  - f_peak,n = peak firing rate of last motor unit

#### Membrane Dynamics Parameters:

**5. Membrane Time Constant: τ_m(i)**
- Definition: Time constant governing membrane potential dynamics
- Unit: milliseconds (ms)
- Relationship (from paper): Inversely related to motor unit size
- Typical values mentioned: range from ~5-10 ms for large units to ~10-20 ms for small units

**6. AHP Time Constant: τ_AHP(i)**
- Definition: Time constant governing afterhyperpolarization decay
- Unit: milliseconds (ms)
- Distribution: Related to motor unit type (slow vs fast)

**7. AHP Amplitude: A_AHP(i)**
- Definition: Peak amplitude of afterhyperpolarization following a spike
- Unit: mV
- Effect: Determines the depth of hyperpolarization and influences firing rate modulation

---

## Inputs

### 1. **Excitatory Drive: e(t)**
- Source: Descending command from higher motor centers
- Unit: Normalized (0 to 1) or in units compatible with RTE
- Time-varying: Yes
- Description: Represents the net excitatory synaptic input to the motor neuron pool
- Note from paper: This is the primary control signal that modulates motor unit recruitment and firing rates

### 2. **Synaptic Noise: ξ(t)**
- Source: Stochastic fluctuations in synaptic input
- Type: Gaussian white noise (as stated in paper)
- Statistics: Zero mean, standard deviation σ_noise
- Purpose: Introduces physiological variability in discharge timing
- Implementation: Added to the effective drive

---

## Outputs

### 1. **Spike Trains: S_i(t)**
- Format: Binary pulse train for each motor unit i
- Value: 1 at spike times, 0 otherwise
- Description: Discrete action potentials generated by each recruited motor unit
- Destination: Serves as input to the muscle fiber activation dynamics (Block 2)

### 2. **Instantaneous Firing Rates: f_i(t)**
- Definition: Reciprocal of inter-spike interval
- Unit: pps or Hz
- Description: Continuous measure of motor unit discharge rate
- Use: For analysis and validation against experimental data

## Equations (Exact as in Paper)

### 1. Membrane Potential Dynamics

The membrane potential V_i(t) for motor unit i evolves according to:

```
τ_m(i) · dV_i/dt = -V_i(t) + g · [e(t) + ξ(t)] - AHP_i(t)
```

where:
- τ_m(i) = membrane time constant for motor unit i
- V_i(t) = membrane potential
- g = gain factor converting synaptic drive to membrane potential
- e(t) = excitatory drive
- ξ(t) = synaptic noise
- AHP_i(t) = afterhyperpolarization current

### 2. Afterhyperpolarization Dynamics

The AHP evolves according to:

```
τ_AHP(i) · dAHP_i/dt = -AHP_i(t)
```

with the reset condition:
```
When spike occurs: AHP_i(t) → AHP_i(t) + A_AHP(i)
```

### 3. Spike Generation

A spike is generated when:

```
V_i(t) ≥ θ(i)
```

Upon spike generation:
- Spike is recorded: S_i(t) = 1
- AHP is incremented: AHP_i(t) ← AHP_i(t) + A_AHP(i)
- Membrane potential may be reset (implementation detail)

### 4. Recruitment and De-recruitment

**Recruitment occurs when:**
```
Effective drive = e(t) + ξ(t) ≥ RTE(i)
```

**De-recruitment occurs when:**
```
Effective drive = e(t) + ξ(t) < RTE(i) - ΔH
```

where ΔH is a hysteresis term (mentioned in paper to prevent rapid on-off switching)

### 5. Firing Rate Modulation

The relationship between effective drive and firing rate is given by (from paper):

```
f_i(e) = f_min(i) + [f_peak(i) - f_min(i)] · [(e - RTE(i)) / (1 - RTE(i))]
```

for RTE(i) ≤ e ≤ 1

This is the **target firing rate** that the motor neuron attempts to maintain through its intrinsic dynamics.

## Interactions with Other Blocks

### Receives From:
- **External Input**: Excitatory drive e(t) representing the descending motor command
- **Feedback Mechanisms** (if implemented): Afferent feedback from muscle spindles or Golgi tendon organs (mentioned as potential extension in paper)

### Sends To:
- **Block 2 (Muscle Fiber Model)**: Spike trains S_i(t) for each motor unit
  - Each spike triggers activation dynamics in the corresponding muscle fibers
  - The timing and pattern of spikes determine the force production

### Internal Interactions:
- Motor units within the pool are **independent** in this model
- No direct lateral interactions between motor neurons
- Common input (e(t)) provides the only coupling mechanism

---

## Update Rate / Time Resolution

### Numerical Integration:
- **Time step (Δt)**: The paper states that the differential equations are solved using a **fixed-step numerical integration method**
- **Typical resolution**: **0.1 ms to 1 ms** (implicit from firing rate ranges and need to capture spike timing accurately)
- **Method**: Euler method or Runge-Kutta (not explicitly specified in paper)

### Justification for Time Resolution:
- Must be fine enough to:
  - Accurately capture membrane dynamics (τ_m ~ 5-20 ms)
  - Resolve individual spikes
  - Properly simulate AHP decay (τ_AHP ~ 10-100 ms depending on motor unit type)
  - Capture noise fluctuations

### Sampling of Outputs:
- Spike trains are discrete events, recorded at exact crossing times
- Firing rates can be computed from inter-spike intervals

## Ambiguities and Implicit Assumptions

### 1. **Exact Noise Implementation**
**Quote from paper (Section 2.1.2):** *"Synaptic noise was modeled as Gaussian white noise added to the excitatory drive."*

**Implicit detail**: The exact standard deviation σ_noise is not specified in the equations section but is mentioned in the simulation parameters (typically 1-5% of the drive range).

### 2. **Membrane Potential Reset**
**Ambiguity**: The paper does not explicitly state whether V_i(t) is reset to a specific value after a spike or simply continues to evolve according to the differential equation with the added AHP.

**Likely implementation** (based on standard practice): No hard reset, membrane potential continues to evolve with AHP providing the refractory effect.

### 3. **Gain Factor g**
**Implicit**: The gain factor g that converts dimensionless drive e(t) to membrane potential (mV) is not explicitly given as an equation but is implied to scale the input appropriately.

### 4. **Hysteresis Value ΔH**
**Quote from paper:** *"A small hysteresis was implemented to prevent rapid recruitment and de-recruitment."*

**Implicit**: The exact value of ΔH is not specified in the main equations but is mentioned in simulation parameters (typically 1-2% of RTE).

### 5. **Relationship Between θ(i) and RTE(i)**
**Implicit**: The paper does not provide an explicit equation relating the firing threshold θ(i) to the recruitment threshold RTE(i), though they are clearly related through the gain factor and baseline membrane potential.

## Summary

Block 1 implements a **physiologically-based motor neuron pool** where:
- Motor units are recruited according to the **size principle** (Henneman's principle)
- Each motor neuron is modeled as a **leaky integrator** with afterhyperpolarization
- Firing rates are modulated by the **effective synaptic drive**
- **Stochastic noise** introduces realistic variability
- The output is a set of **discrete spike trains** that drive muscle fiber activation

This block captures the essential neural mechanisms that transform a smooth control signal into the discrete, stochastic discharge patterns observed in real motor units during voluntary contractions.
